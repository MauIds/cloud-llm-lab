# Cloud LLM Lab

Build, fine-tune and deploy language models from first principles.

**MentorLM**: fine-tuning de Qwen3.5-4B (SFT + LoRA) en Modal (GPU serverless) para crear un tutor de LLM Engineering en español.

**TinyGPT**: un Transformer pequeño construido desde cero en PyTorch, guiado por MentorLM.

Ver `PROJECT_PLAN_Cloud_LLM_Lab.md` para el plan completo.
